Agent skills

routeros-skills is 34 agent skills for RouterOS 7, grouped here by area. Each skill is a folder in the repository with a SKILL.md and MikroTik's documentation for that area as plain Markdown, and each is listed on skills.sh. Start with routeros-fundamentals: it explains the console conventions and maps the rest.

INSTALL
npx skills add wiresage/routeros-skills picks skills interactively; add -s routeros-firewall routeros-vpn to choose by name. The repository also ships plain installers for Claude Code, Codex and GitHub Copilot — see the install section. Independent of MikroTik MCP and routeros-lsp: use any one alone.
